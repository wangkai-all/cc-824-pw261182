# 方法假设、口径与边界

本文档固定系统的建模假设与计算口径，保证「分析与实际检测台账一致」，并明确哪些结论是有条件的。

## 1. 相关风险模型（不做 i.i.d. 假设）

每个样品携带一个基线风险 `baseRisk`，并关联零个或多个**潜在事件**（共同来源，如冷链异常、
同一采样点暴露）。每个事件 `e` 有先验发生概率 `probability_e` 与条件抬升 `lift_e`。

- 事件状态相互独立地按伯努利抽样；样品真值在给定事件状态下条件独立。
- 样品在某事件状态下的条件阳性概率：
  `condP = 1 - (1 - baseRisk)·Π_{活跃且关联的 e}(1 - lift_e)`，
  即基线与各事件抬升以「不发生」概率连乘，避免概率超过 1。
- 边际风险 `marginalRisk` 对所有相关事件组合（2^k）边缘化得到。
- **相关性**来自共享事件：事件发生时一批关联样品同时被抬升。联合分布
  `P(事件状态, 各样品真值)` 在 `enumerateJointStates` 中精确枚举，后验与决策都在这个联合空间上
  进行，因此样品之间不假设独立。

## 2. 池大小依赖的检测性能（稀释与污染）

- 灵敏度（池内含真实阳性时出阳性的概率）：
  `Se(k) = maxSe · decay^log2(k)`，池大小每翻倍一次，灵敏度乘一次 `dilutionDecay`。
- 特异性（池内全阴时出阴性的概率）：
  `Sp(k) = baseSp · (1 - contamination)^(k-1)`；污染轮再额外扣减固定假阳增量。
- 单样品检测 `k=1` 时灵敏度最高（`maxSe`，默认 0.98），但**仍小于 1**，所以单检也可能假阴。
- 一次检测从池内**每个**样品扣除等量等分样 `aliquotVolume`；剩余样量不足一次等分样的样品
  不能再入池，约束在台账写入时强制（违规抛错，而不是静默丢样）。

## 3. 台账：唯一事实来源

台账是**只追加的不可变事件流**，事件类型为 TEST / CORRECTION / CONTAMINATION / NOTE。

- 每次 TEST 记录池成员、轮次、结果、污染标记、费用与等分样量，并即时扣减样量。
- **结果更正不抹除原始记录**，而是追加一条 CORRECTION 指向原 TEST；`deriveEffectiveTests`
  负责把更正应用到派生视图，分析侧始终读到「当前生效」结果。
- 所有派生量（剩余样量、累计费用、轮次、后验）都由台账计算，页面刷新即可重建，无第二份状态。
- `audit()` 自检：样量不得为负、更正必须指向存在的检测、费用口径一致。

## 4. 后验推断

在联合状态空间上做贝叶斯更新，似然按第 2 节的池大小依赖 Se/Sp 与污染标记计算：

- **精确枚举**：当 `2^(N+K)` 不超过枚举上限（默认 4096）时，对全部联合状态加权归一化。
- **粒子推断（SIS）**：大样本时先按先验抽取粒子，再以观测似然作重要性权重（权重只含似然，
  因为粒子本身已按先验抽样），并报告有效样本量 ESS。
- 观测在当前模型下似然为 0（参数或更正互相矛盾）时显式报错，而不是给出虚假后验。

## 5. 决策

### 一步前瞻推荐（网页「下一步」）

在当前后验的联合状态上评估有限个合规候选分池（定长切分 + 针对最近阳性池的全单检/二分/复测），
用两阶段（Dorfman 式）口径计算期望代价：

- 单样品池（`k=1`）视为**终局确认**，无后续拆检费；阳性样品以 `1-Se(1)` 计假阴漏检。
- 多成员池：阳性池结果触发下一轮对可拆检成员逐个单检，计入期望拆检费；阴性池不拆检，池内
  阳性整体计漏；不在任何池中的阳性样品按后验期望计漏。
- 总代价 = 本轮检测费 + 期望拆检费 + λ·期望漏检数；与「停止」候选（代价 = λ·当前期望残余阳性）
  取最小。**只读取台账中的生效结果，不读取真值。**

### 小样本精确核对（N≤6）

`exactOptimalPolicy` 在联合信念状态上做动态规划，枚举「选池检测 → 按阴/阳结果分支」的完整
策略树，分别求费用最小树与漏检受限树，用于核对贪婪推荐的方向。

- 一个关键事实（贝叶斯边际守恒）：**单纯「检测后停止」不会降低期望漏检数**——观测只改变信念，
  真正降低漏检的是在叶子层对可检测样品执行的确认检测。因此叶子节点显式按 `1-Se(1)` 计假阴，
  无样可测的阳性样品计为必漏。
- 受限树在深度/样量约束下可能不可达，此时返回 `null` 并标注，而不是伪造可行解。
- 叶子口径假设「所有仍可检测的样品在叶子层都能被单检」，因此精确枚举定位为 **N≤6 的核对工具**，
  不作为大样本的生产策略；大样本以蒙特卡洛评估为准。

## 6. 整批评估与敏感性

- `evaluateStrategies` 对大量虚构批次抽样真值，逐轮调用推荐策略，检测结果按模型抽样（含可选
  污染轮），最后对照真值统计费用、漏检率、每批漏检数、单检误报率、样量耗尽率与中止率。
- 漏检受限启发式用更高的 λ（默认 5×）驱动更多拆检；其精确对应物是第 5 节的受限 DP 树。
- `sensitivityAnalysis` 对基线风险与事件概率各取 0.5×/1×/2×（共 9 情景），报告指标区间。
  区间宽度反映假设的证据不足。

## 7. 边界与免责

1. 全部输入为虚构；模型参数（Se/Sp 曲线、事件概率、抬升、费用）是演示设定，需用真实数据校准。
2. 灵敏度恒小于 1、样量有限，**系统在任何情景下都不宣称保证发现全部异常样品**；输出是期望与区间。
3. 粒子推断带蒙特卡洛误差，ESS 偏低时应增加粒子数或改用更小批次的精确枚举。
4. 精确 DP 的叶子单检假设仅在 N≤6 核对场景成立；超出范围请依赖仿真指标而非 DP 树。
5. 污染被建模为实验台层面的加性假阳风险并逐轮标记；若真实污染机制不同，需替换 `assay.mjs` 中的
   `specificityAt` 口径，台账与推断层无需改动。
